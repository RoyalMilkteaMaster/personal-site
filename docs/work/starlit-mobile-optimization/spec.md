# 手機載入、轉場與視覺修正

狀態：需求、Spec 與六張 Ticket 拆分均已由使用者核准。2026-09-21。

## 問題
手機實機首次載入過久，點關於我／我的專案時卡住、內容不出現；奶茶段長句裁切、背面視角與桌面差異過大。月亮合照誤移除應保留的摸貓手。

## 目標
優先改善手機載入及使用流程。桌面效果最高優先，除月亮核准修正外不改變既有視覺與正常互動；粒子數不減少。

## User Stories
1. 身為手機訪客，我希望縮短進站等待並順利進入章節，以便閱讀網站。
2. 身為手機訪客，我希望完整看見文字、背面人物視角接近桌面，以便得到一致的體驗。
3. 身為網站擁有者，我希望保留满意的桌面效果，並恢復月亮裡摸貓的動作。

## 需求與行為
- R1 手機載入：先量測瓶頸，再改善下載、準備及執行等待；不可減粒子或以降低畫質冒充優化。
- R2 手機章節：關於我／我的專案必須可進入；3D慢載入或失敗不應使內容永久不可見。正常動畫保留，錯誤不冒充成功，維持合理重試與重播。
- R3 手機排版：奶茶段原文完整呈現，左右保留空間、自然換行，保留字級層次與顯字行為；不縮成難讀小字。
- R4 手機背面：以現有桌面同幕觀看方向、俯仰及人物朝向為基準；直式畫面可調整距離及留白。相鄰幕轉場保持連續，文字不遮擋主體，桌面相機不變。
- R5 月亮：恢復人物右側伸向貓頭的手及接觸動作；只移除左上方另一隻手。維持柔和低對比與既有整體構圖，原始素材保留。
- R6 桌面保護：除R5外保留正常外觀、畫質、動畫、閱讀節奏、雙語、章節、互動及重播；手機限定修改優先，共用修改須證明無退步。
- R7 WebGPU：評估相容性及本專案瓶頸的適用性；涉及實測比較時保持相同粒子數及視覺條件。不得宣稱未量測收益，不直接替換正式引擎。

## 實作決策
- 資料與所有權：沿用雙語文案、既有靜態資產及瀏覽器偏好；不新增後端或資料服務。
- 模組責任與公開介面：沿用 StarlitExperience／StarlitReader／StarlitShell、mountFantasyScene、既有相機及renderer接縫；沿用章節命令與場景回報，不另造平行狀態真相。
- Schema、API contract與系統互動：不新增公開API或Schema；現有錯誤語意維持，章節可見性按R2修正。
- 相容、遷移與技術限制：沿用React／vinext／WebGL2；粒子數維持，預設不降解析度、不簡化轉場。優化方法由量測決定，需改架構或視覺時回報。
- 根目錄：D:/workstationD/personal-site；WSL /mnt/d/workstationD/personal-site。Spec／Tickets保存在docs/work，本輪證據放本專案work，不寫回OneDrive。

## 驗收條件
- AC1 對手機冷／暖載入分開量測，在同裝置、瀏覽器、網路、快取及建置模式下比較多次紀錄，報告載入資源量、等待可用內容時間與主要瓶頸；須有可重現改善，不以開發版對正式版作唯一產品優化證據。不預設未核准的秒數／FPS門檻。
- AC2 手機完整開場後進關於我／我的專案、切章節、返回及重播可完成；正常、慢載入及3D錯誤情境下不會持續卡住或空白。錯誤仍可識別，正常動畫不省略。
- AC3 手機中英文長句均完整可讀，無水平裁切；檢驗直式窄螢幕及瀏覽器工具列造成的可視高度變化。
- AC4 手機背面與桌面同幕並排對照，方向、俯仰及人物朝向相近；完整播放進出該幕，無鏡頭跳接、意外裁切或文字遮擋。桌面鏡頭保持原樣，視覺由使用者確認。
- AC5 月亮以原圖與目前版本對照：摸貓手恢復，左上方另一隻手移除，柔和低對比維持；桌面及手機皆驗證，視覺由使用者確認。
- AC6 粒子數不降低；桌面修改前後同環境的關鍵畫面與完整流程對照，除AC5外視覺及功能無退步。效能紀錄需揭露測試誤差，不以單次數值宣稱提升或下降。
- AC7 WebGPU評估區分已查證支援、實測結果、未驗證推論及遷移成本；不支援的環境仍沿用現有WebGL2。無全面遷移。

## 測試決策
- 公開行為：載入可用性、章節進入與恢復、雙語換行、背面取景、重播及桌面回歸。
- 測試接縫：沿用既有場景命令／回報、相機函式與reader互動測試；以瀏覽器連續操作、資源／效能紀錄及畫面對照驗證最終結果。
- 既有測試模式：沿用node斷言及既有瀏覽器驗證、建置檢查；依變更範圍執行，不以靜態來源字串取代行為驗收。
- 不應耦合的實作細節：不指定壓縮工具、緩衝區配置或任意效能數字；不能削弱測試來掩蓋原問題。
- 實機邊界：手機尺寸模擬不代表iPhone效能通過。記錄實際裝置／系統／瀏覽器；無實機存取時交付可由使用者手機驗證的預覽，明列待實機確認，不宣稱完成該項。
