# 02 — 手機章節轉場與恢復

- Spec：`../spec.md`
- Blocked by：無

## 交付成果
手機可由開場进入關於我／我的專案並繼續閱讀；改善轉場阻塞，慢載入或3D錯誤不使章節持續空白。覆蓋 R2、R6／AC2、AC6。

## 驗收條件
- 實際操作完整開場、進入兩個入口、切換章節、返回及重播，流程均可完成。
- 正常、慢載入與3D錯誤情境下，章節不會持續卡住或空白；錯誤仍可識別，重試與重播可正常使用。
- 保留正常動畫、粒子數及画質，不以省略轉場冒充修復。
- 留存轉場前後同環境操作／效能證據及相關行為驗證，區分已確認根因與未驗證推論。
- 桌面正常章節、動畫、雙語與重播不退步；實機驗收限制依 Spec 揭露。

## 必要寫入範圍
場景生命週期可能與 01 共用；StarlitExperience／StarlitReader／StarlitShell 與 03 的排版、04 的月亮接入也可能相交，需協調局部修改。
