# 11 首幕優先、後續資源背景準備
使用者核准：「延後下載後面章節才需要的資料，讓首幕更早開始。這邊幫我做一下」，並關心快速前往後段是否反而卡住。

快速滑動／切章節而資料未到時，不可崩潰、永久空白、假裝已準備好或吞掉最後操作；保留可讀內容與清楚可恢復等待，資料就緒後銜接最新目標。重播、連點、語言、載入失敗／重試、卸載／WebGL失效須保持合理。背景準備不能每幀重做或導入未量測的卡頓。
