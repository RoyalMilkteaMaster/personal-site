# 01 — 手機載入優化

- Spec：`../spec.md`
- Blocked by：無

## 交付成果
改善手機首次進站及重訪的載入等待，保留粒子數與視覺效果；提供可重現的瓶頸與改善證據。覆蓋 R1、R6／AC1、AC6。

## 驗收條件
- 同裝置、瀏覽器、網路、快取與建置模式下，分開比較多次冷／暖載入；記錄資源量、可用內容等待時間及瓶頸，顯示可重現改善。
- 區分開發通道與產品負擔，不以開發版對正式版作唯一優化證據，不宣稱未量測收益。
- 粒子數維持；不降低畫質或省略正常動畫。桌面同環境關鍵畫面、載入及操作回歸無退步。
- 沿用既有架構；若改善必須犧牲視覺或改變架構，回報而不自行降低標準。
- 實機不足時依 Spec 明列待手機確認項目，不用尺寸模擬冒充實機效能驗收。

## 必要寫入範圍
載入及場景生命週期可能與 02 共用 mountFantasyScene／renderer 等模組，需協調修改；不是先後依賴或檔案白名單。
