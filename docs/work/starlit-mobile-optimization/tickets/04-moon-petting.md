# 04 — 月亮恢復摸貓動作

- Spec：`../spec.md`
- Blocked by：無

## 交付成果
月亮合照恢復人物右側伸向貓頭的手與摸貓接觸動作，只移除左上方另一隻手，維持柔和低對比及既有構圖。覆蓋 R5、R6／AC5、AC6。

## 驗收條件
- 以原始合照與目前月亮版本對照，確認靠近貓頭的摸貓手恢復，左上方另一隻手移除，沒有誤刪或多出肢體。
- 人物及月亮維持柔和低對比，不回復過度寫實、高對比的效果；原始素材保留。
- 桌面及手機皆檢查月亮構圖、遮罩、邊缘與顯示比例，無額外排版或互動變更。
- 除核准的月亮修正外，桌面其他效果不變；最終視覺由使用者確認。

## 必要寫入範圍
月亮素材及 StarlitShell 的素材接入可能與 02、03 共用檔案，需協調接入位置，不修改其互動與相機責任。
