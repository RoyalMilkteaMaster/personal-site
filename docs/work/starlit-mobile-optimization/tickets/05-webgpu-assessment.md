# 05 — WebGPU 適用性評估

- Spec：`../spec.md`
- Blocked by：無

## 交付成果
提供有來源的 WebGPU 相容性、本站瓶頸適用性、效益證據及遷移成本結論，供後續決定，不替換正式引擎。覆蓋 R7、R6／AC7、AC6。

## 驗收條件
- 明列已查證瀏覽器／裝置支援條件、目前WebGL2瓶頸，以及WebGPU能與不能改善的部分，引用第一手來源。
- 明確區分實測結果與推論；如進行比較，採相同粒子數、視覺條件及可比較環境，不虛構速度提升。
- 說明兼容路徑及遷移成本，結論可供決定是否值得另行規劃，不把全面遷移視為已核准。
- 不更換產品引擎，不影響桌面或手機現有行為；不支援WebGPU的環境仍沿用WebGL2。
