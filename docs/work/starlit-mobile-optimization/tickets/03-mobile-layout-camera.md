# 03 — 手機排版與背面視角

- Spec：`../spec.md`
- Blocked by：無

## 交付成果
手機奶茶段長句完整顯示，背面一幕的觀看角度接近目前桌面，維持前後鏡頭連續及文字可讀。覆蓋 R3、R4、R6／AC3、AC4、AC6。

## 驗收條件
- 中英文長句完整、自然換行且左右有留白，無水平裁切，保留字級層次與顯字行為。
- 驗證直式窄螢幕及瀏覽器工具列造成的可視高度變化，不僅依賴單一桌面模擬尺寸。
- 手機與桌面背面同幕並排對照，觀看方向、俯仰及人物朝向相近；允許直式取景距離及留白差異。
- 完整播放進出背面一幕，無跳接、意外裁切或文字遮擋主體；不修改桌面鏡頭。
- 桌面排版、閱讀節奏、動畫及互動不退步；背面最終視覺由使用者確認。
