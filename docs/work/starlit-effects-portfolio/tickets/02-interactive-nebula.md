# 02 — 操作喚醒星雲背景

- Spec：`../spec.md`
- Blocked by：無

## 交付成果
關於我、我的作品、聯絡資訊保留原背景基調，背景既有很暗、隱約可見的雲與少量星星，提供空間感；光照過時將該處原有雲照成淡金色。提供實際互動預覽，不改人物或開場。

## 驗收條件
- 覆蓋R2及背景相關R6、AC2、AC3、AC7、AC8。
- 未操作時有很暗、難以看清但隱約可見的雲和少量星星，形成空間層次，維持原本背景基調。雲紋理在背景微幅緩慢漂移，不跟隨滑鼠；光僅照亮局部既有雲成淡金色，移開回暗。不可平時完全移除雲或恢復被否決的亮紫雲幕。
- 滑鼠滑過喚醒比一張卡稍寬的淡金光與附近星芒，邊界柔散、沒有明顯圓形白光斑；雲光與星芒皆約1.5秒、相同曲線自然淡去，不累積無限拖尾。
- 手機觸碰及滑動可喚醒，放開後淡去；實際驗證捲動、點卡與連結未受阻礙，內容文字不被光效蓋住。
- 三個內容頁皆有一致效果；開場與左側人物星空維持現狀，不增加星座線、流星或整片流動星塵。
- 切離適用頁面或隱藏分頁暫停，卸載取消動畫與監聽、釋放資源，恢復後無重複效果；不得累積無限餘光或以未量測推斷低成本。
- 使用者在預覽中確認平時暗度、操作反應與餘光；未回覆則明示待確認。完成座標、餘光及生命週期的必要行為驗證。

## 必要寫入範圍
- 與01、04共用StarlitShell及樣式，與05可能共用shell檔案；本票負責內容背景、輸入與生命週期接縫，避免改寫其他票的卡片／社群內容。


## 2026-09-20 最新修訂：提前 1 秒與星雲接縫
外框開始時間改為原燒穿結束前 1000ms（約2800ms），覆蓋稍早700ms提前量；放慢的增粗時長維持700ms。背景的現有美感被使用者否決：須參考真實星雲的疏密層次、雲絲、暗塵遮蔽，使暗雲與淡金照明適合目前主題，仍固定於背景、保持文字可讀。桌面光效以右側內容區左緣為0%，到內容區寬度1/3處達100%，中間平順漸強；分界和左側人物星空完全無打光，包含受光星芒，不得以光源中心強度代替逐像素接縫衰減。手機沒有左右接縫，不套用會不必要削弱內容的左側衰減。其餘核准範圍不變。


## 2026-09-20 使用者接受星雲造型後的微調（覆蓋先前相衝條文）
使用者明確說「現在這樣非常好」，接受當前造型方向，再要求三項微調：
1. 右側背景星星沿用左侧旋轉星空實際使用的多色配色，不僅金色；星星在滑鼠移開後稍慢淡暗。以既有配色來源為依據，保持星雲淡金光；可採星光約2.2秒淡出而雲光維持1.6秒，微調須保留接縫逐像素零光規則。
2. 背景加入非常輕微、緩慢的浮動感；保持已接受雲形、暗度、空間感、閱讀性與暗／亮共用雲場。不得讓桌面接縫遮罩隨雲移動；reduced-motion 停止裝飾運動，隱藏時暫停／清理。
3. 外框增粗從火第一次接觸卡片外緣開始（細線），隨火接觸外緣的範圍增加而增粗至3.5px。取代固定提前1秒／固定700ms增粗，以實際共用火焰／揭露幾何進度為準，GL與2D一致，不靠無關固定timeout猜測；最終流動配色／7秒速度不變，不復活火舌。
本次仍為原01／02票修訂，原其他需求與邊界維持。造型接受不代替新動態的最後視覺確認。

### 2026-09-20 浮動幅度再次微調（最新）
使用者在看過 revision-5 後回覆雲與星浮動太少、看不出來，要求稍微多一點。提高雲層幅度與速度，讓數秒觀察可辨；星點也須有可辨但輕微的慢漂移（原revision5星點未實際位移）。保留三色、2.2s星餘光、1.6s雲光與目前造型，不改01火接觸外框。可先以雲24秒單程約12px/9px、星32秒約6px/4px為微調起點，依正常預覽判斷；避免整片明顯平移或過度晃動。暗亮雲同相位、遮罩與指標光固定，星移動後喚醒仍合理，減少動態／hidden停動。手機同樣克制。

最新使用者追加：背景星星金色約50%，其餘50%。本輪將其餘均分淡藍25%／淡紫25%，待機遠星及互動星芒一致；保留星點密度與位置。


### 2026-09-20 最新：雲星同步淡出
使用者要求星雲變暗速度與星星相同，取代雲1.6秒／星2.2秒分離。統一2.2秒與相同衰減曲線；不改浮動幅度、配色比例、接縫或外框。


### 2026-09-20 最新視覺回覆：外框接受／雲加強／淡出1.5秒
使用者明確說「火焰現在很好」，接受01 revision9接觸驅動邊框，不再調整。本版星雲仍難察覺浮動，要求再加強；僅提高雲層位移與速度，保留造型、星點既有6/-4px32秒浮動與50/25/25配色、接縫固定。建議雲24/-18px、12秒單程往返，讓6秒約半程12/-9px可辨，暗亮同相位且reduced/hidden維持。雲光與星光共用淡出改1500ms，覆蓋2200ms。
