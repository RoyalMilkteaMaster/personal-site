# 03 — 五個專屬單色圖標

- Spec：`../spec.md`
- Blocked by：無

## 交付成果
提供五個作品的單色圖標及實際卡片使用尺寸的視覺預覽，讓使用者確認造型、角色辨識與配色；正式素材可由網站自身載入，供04接入。

## 驗收條件
- 覆蓋R3圖標／配色、AC4圖標部分及AC8圖標確認。
- Market Council為奶茶金比特幣₿；CB為藍色調色盤；奶茶流為紫色純奶茶杯；LoL為粉紅色L＋圓環；雪絨為靛色專屬貓娘頭像。
- CB改用可辨識的調色盤，使用者已撤回蕾瓦娜絲角色頭像；既有原圖與歷史證據保留，不覆寫。
- 雪絨比被否決首版更可愛，保留角色貓耳、瀏海、臉部特徵，不以通用貓頭代替、不加通知符號。奶茶杯不加流程節點。
- 五個圖標單色、視覺份量一致，在實際開啟與關閉卡片所需尺寸均清楚可辨，不因縮小失去主要特徵。
- 預覽可直接看到全部五個圖標與對應配色；保留素材來源，交付不依賴第三方圖片熱連結。
- 使用者確認圖標觀感後供04接入；未回覆時標示待確認，不將檔案存在或測試成功當作視覺核准。

## 必要寫入範圍
- 交付圖標素材及必要展示接縫；若展示使用StarlitShell或共用樣式，與01、02、05協調增量，避免覆蓋。04依本票產物接入，不另製作第二套同義素材。

- 最新使用者修正：CB只換調色盤圖標，名稱／定位維持原平台；圖標預覽名稱也保留平台名稱，不叫CB調色盤。
