# 05 — 移除 LinkedIn 入口

- Spec：`../spec.md`
- Blocked by：無
- 2026-09-19 使用者實作中修訂：「算了 直接改成把linkedin拿掉好了」。原可達性查驗要求撤回，歷史authwall證據保留，不再作本票阻擋。

## 交付成果
移除網站的LinkedIn入口及不再使用的專屬圖示／雙語文案。保留GitHub、Instagram、Email等其他既有聯絡方式與操作，不新增替代入口。

## 驗收條件
- 覆蓋修訂後R5、AC6。
- 中文與英文的聯絡資訊及頁尾不再顯示或連往LinkedIn。
- 共用社群資料保持單一來源；清理已不再使用的LinkedIn專屬圖示／文案。
- 其他既有社群與Email的名稱、目的地、開啟行為及可及性維持。
- 從主預覽實際切換語言、查看聯絡資訊／頁尾；以適用render／資料行為檢查驗證，不能只改測試斷言而漏產品入口。
- 不必登入LinkedIn，不再以外站是否可達作完成條件。

## 必要寫入範圍
共用社群資料、呈現、雙語文案與相鄰測試。shell與01／02／04重疊時只做增量，保留卡片、背景、人物與開場成果。原始歷史證據不刪除。
