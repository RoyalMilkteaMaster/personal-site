## 驗收條件
- 覆蓋R3排列／整合、R4、AC4、AC5及整合相關R6；使用03已確認的圖標產物。
- 順序為Market Council、CB、奶茶流、LoL Highlights、雪絨；依Spec使用金、藍、紫、粉紅、靛，圖標／流動框配色對應同一作品。
- 桌面每列三張、第二列兩張靠左；手機單欄依序排列，無橫向溢出或文字、連結互相遮擋。
- LoL與雪絨中文簡介逐字符合Spec核准文案，英文等義且不增加功能宣稱；兩件各只新增提供的GitHub連結，不虛構展示影片。
- 原三件作品文案、連結與主要操作保留；3.5px框與16／14px字級維持。
- 中英文切換、五卡開合及連結操作可用；從共用資料讀取的舊首頁也有五件，無第二套三件專用資料，舊首頁既有操作不回歸。
- 實際檢查桌面與手機尺寸的最終圖標及文字；資料、連結與必要型別／既有檢查通過，不以字串測試取代排版驗收。
