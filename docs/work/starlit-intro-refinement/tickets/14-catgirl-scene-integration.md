# 14 — 貓娘與品牌道具主場景整合

- Spec：`../spec.md`
- Blocked by：12、13

## 交付成果

貓娘在主預覽真正與可動R、皇冠及3D杯互動，完整循環且可隨時退出開場。

## 驗收條件

- A05、A06集成與A12：R拿起後原字位置不能殘留另一個R。
- 手與道具對位、前後遮擋合理，拿放無跳位；品牌大小與漸層保留。
- 完整播放一輪、30秒待機漂游、第二輪開始，無瞬移；不能用獨立viewer代替。
- 任何動作中可平順進介紹；重播、回開場與隱藏恢復無重複角色或殘留道具。

## 必要寫入範圍

- 與12／13共享資產，與11／17共享場景生命週期；統一鏡頭和播放控制。
