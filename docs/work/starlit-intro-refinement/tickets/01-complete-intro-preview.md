## 驗收條件

- 等待幕只辨認星空，星點豐富、緩慢旋轉且不同步閃爍；等待時逐行呈現四句序詩，必須 CLICK 才拉到完整正臉，未啟動不自動離開。
- Spec 五段中文全文與標點無遺漏；正臉介紹鏡頭固定，接背面志向，喝奶茶句開始轉向背景的獨立貓耳奶茶杯星座。杯子持續自轉且能看出立體厚度，與手掌及人物無關。
- 最後回到正面完整人物構圖並顯示結尾，閱讀完成後回報完成以接關於我；不得回到正臉近景或另加選擇幕。
- 文字完成後依長度停留再自動接續，完成後可點擊／鍵盤提前繼續，未完成不得提前轉幕；沒有略過入口。重播回到星空等待；切章節不重播。
- 離開分頁或手機切背景暫停進度，返回從原處接續；重複點擊與重播不造成跨幕、消失或時間跳躍。
- 右側少量星點聚散、短暫星座線與偶爾一兩個貓爪／奶茶圖像不遮文字；現有星火不規則局部變亮再回落，保留人物美感、章節姿態及手持物。
- 必要 3D 啟動失敗顯示說明及可操作的重試，不以 done 狀態轉純文字；不製作簡化版本。手機仍可完整播放與閱讀。
- 附連續播放、關鍵中間畫格及適用互動測試證據；正式首頁在預覽確認前維持既有體驗，不重新啟動舊人物建模工作。
