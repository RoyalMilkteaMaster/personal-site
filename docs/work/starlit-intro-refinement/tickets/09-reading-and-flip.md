# 09 — 閱讀節奏與文字翻轉

- Spec：`../spec.md`
- Blocked by：無

## 交付成果

主預覽文字固定位置逐句顯現，整段完成後才接受向下推進；追求按毛哥實際效果翻轉一次。

## 驗收條件

- A01、A02：實際對照毛哥顯字／翻字的方向、節奏與立體感，不以整塊淡入代替。
- 顯字中向下滾／點擊不加速、不跳段、不累積；向上可返回，停止操作仍逐句播完。
- 開場按鍵／點擊／滾輪可進介紹，不等貓娘；技藝→自由→極限停住不循環。
- 中英、回讀、重播與背景暫停恢復皆以實際輸入驗證。

## 必要寫入範圍

- 與10共用StarlitShell／樣式，與17共享輸入與回報；閱讀門檻和章節轉場分工。
