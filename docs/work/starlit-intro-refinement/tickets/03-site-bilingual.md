# 03 — 整站中英文與語言偏好

- Spec：`../spec.md`
- Blocked by：01 完整星空開場預覽、02 品牌、固定導覽與社群入口

## 交付成果

完整預覽可切換整站中英文，五幕及所有頁面內容均翻譯並可閱讀，語言選擇在當前瀏覽器保存。可提前準備翻譯，但完整驗收需要 01 的五幕與 02 的介面。

覆蓋 R09 的語言部分、R06 的雙語閱讀及切換行為、R11 的雙語手機呈現；驗收 A03、A06、A08 相關部分。

## 驗收條件

- 五幕、關於我、作品、聯絡、導覽、按鈕及錯誤／重試介面均有對應中英文；不僅翻譯選單，不因翻譯新增或改寫個人事實。
- Spec 五段中文全文保留；英文詩及敘事兼顧意境與閱讀節奏，提供完整可檢視版本供預覽確認。
- 切語言保留目前章節、幕及鏡頭位置，不重播、不自動略過目前內容；停留時間依該語言的文字長度估算，不沿用固定三秒。
- 重播、重新整理與重訪保留語言偏好，僅限目前瀏覽器；與靜音偏好各自保留，不能互相覆蓋。
- 桌面／手機中文及英文皆無裁字、遮擋或不可操作的控制項；頁面背景暫停不被切語言破壞。
- 內容集中在同一前端管理、作品保持唯一資料來源；提供相關行為測試及兩種語言實際播放／頁面檢查證據。

## 必要寫入範圍

- 與 04 共用右上角控制區、偏好讀寫、錯誤文字及開場命令／回報接縫。協調頁面與場景改動，不能覆蓋聲音控制或新增另一套開場時間軸。
