# 02 — 品牌、固定導覽與社群入口

- Spec：`../spec.md`
- Blocked by：無

## 交付成果

可獨立預覽及操作的貓耳奶茶杯品牌／分頁圖標、三章節導覽與四個社群入口。預覽可驗證開場期間隱藏及結束後顯示的介面狀態；與完整開場實際出場時機於 05 整合驗證，不需等待 01 才開始。

覆蓋 R10、R11 的介面部分及 R12 的預覽限制；驗收 A07–A09 對應部分。

## 驗收條件

- 左上角與預覽分頁可見同系列簡化單色貓耳奶茶杯，具有貓耳杯蓋、杯身及星形記號，小尺寸仍清楚。
- 01 關於我、02 我的作品、03 聯絡資訊具有可辨識邊框及淡底，選中奶茶金底深色字；可操作並切換對應現有內容，作品資料與聯絡功能保留。
- 導覽在內容區上方固定，長內容捲動時不移動、不遮住文字；手機可操作且不溢出。
- 可驗證開場期間無三章節按鈕、完成後顯示並預設關於我的狀態；不增加要求訪客先選擇章節的頁面。
- 四個社群入口具可辨識圖示與操作狀態，實際 href 分別符合 Spec 的 GitHub、Instagram、Email、Facebook，不帶轉址或追蹤參數。
- 品牌保留重播操作接縫，正式首頁與分頁圖示在最終整合前不提前替換；附桌面／手機視覺與操作證據。

## 必要寫入範圍

- 與 01 可能共用預覽頁組合及 app/globals.css；本票負責品牌／導覽／社群介面，須協調同檔修改。
- 品牌、頁面布局或圖示可能涉及 app/layout.tsx 與 public/；新增素材不可使正式首頁在預覽確認前套用新體驗。
