## 每次檢查的固定方法

1. 同一模型、相機、時間、縮放與視口，比較實體模型／均勻低亮度星點／最終亮度密度星點；禁止用不同視角比較來掩蓋錯位。
2. 先驗模型完整性、星點對三角形的重心座標重建與部位對應，再驗密度、照明和遮擋。XYZ 固定本身不代表 XYZ 正確。
3. 每位 Agent 都要逐項標示 U01–U08：通過、失敗、未檢查；提供確切版本、角度、畫面路徑與理由。超出分工的項目交給指定同伴，不能自行略過。至少由一位檢查者覆核每項，整體驗收不得有未檢查項。
4. 正面與背面美術參考仍需比較姿勢、構圖、色彩與外觀。不得為了逐像素正面吻合破壞完整模型；任何剩餘差異如實記錄，不宣稱原圖完全一致。
5. 逐角度截圖不能取代整段連續播放；星火還需完整自轉週期。點的 ID、XYZ、基礎色彩與密度在建構後固定。
