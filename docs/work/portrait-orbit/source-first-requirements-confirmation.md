# 原圖優先的人物修正需求 — 已確認

狀態：使用者於 2026-09-13 回覆「確認」，已核准本份要求及頭部／手部兩張修正子票平行派工。原 Spec／Tickets 仍未完成；需求核准不構成成果驗收通過或範圍擴張。

## 1. 外觀基準與模型用途

- 使用者最滿意的原始星點人物圖，是最終外觀的首要驗收基準；首張近景與末張全景應幾乎重現原圖，能一模一樣最好。原始照片及使用者指定側面參考提供相應補充，不以任意生成圖取代原圖。
- 現有 GLB 只是提供大致立體體積、部位關係及旋轉基礎的輔助。它本身的手勢、頭頸姿態與形狀並未獲得外觀認可，不能把它們當成不可修改的正確答案。
- 先根據模型建立接近原圖的大形、比例與姿態，再依原圖細修輪廓、部位連接及星點線條。模型與原圖衝突時，應修模型與呈現以接近原圖，而非降低原圖的驗收要求。
- 沿用已有可用成果作為起點，避免無依據地回到曾被否決的素模重做；但不能因此凍結不自然的原有形狀。必要的局部重塑仍屬修正工作，不要求只能移動幾個點。

## 2. 頭部子票

- 頭髮、臉、頭顱、耳側、下巴、頸部與肩領的整體關係，都須依原圖修正。
- 現有脖子歪斜不是必須保留的特徵。目標是原圖中自然、穩定的頭頸姿態及頸部粗度、長短、角度。
- 使用者要求整個頭相對身體向後調整；需同時考量頭髮、臉、下巴與頸根銜接，不能只將臉向內壓，造成臉縮進頭髮或頭顱的效果。具體位移量以原圖及整體多角度結果判斷。
- 修正側面髮臉錯位、下巴稜線不自然、碎裂或額外亮邊等問題；不能以局部領口接合改善宣稱整個頭部完成。

## 3. 手部子票

- 原 GLB 的手部動作本來就不自然，不能把原手姿視為必須保留的標準。目標是原圖中的手勢、掌向、指形、手指前後層次及手腕關係。
- 優先利用原有可辨認的指體，做整根手指與掌部的協同調整；需要時可修正原本不合適的彎曲、指根、掌形及手腕連接。
- 先前「整根手指小幅微調」是避免破壞形狀的建議方法，不是新的硬性驗收限制。不能把角度小、長度不變、保留原模型彎曲，凌駕於接近原圖且自然的結果。
- 若小幅調整不足，應先檢查大形、掌向、部位對應與變形方式，再有依據地局部重塑。不可為了正面指尖對齊，任意拉長、壓薄或扭曲側面。
- 正面與側面必須同時成立，避免手指重疊、寬橢圓、指根折疊、掌部變形；與星火及袖口的關係也需一致。

## 4. 共同驗收與工作順序

- 原圖／保留版／候選以相同取景尺度並排，先看整體姿態與輪廓，再看局部線條、材質與星點。
- 至少檢查正面、斜側面、左右側面、背面及連續旋轉。原圖未提供的方向，要合理延伸同一角色與姿態，不能假稱每個側面都有原圖真值。
- 最終是具有原圖美感的立體星點人物：保留原圖的亮邊、暗面、疏密與輪廓層次；普通模型材質好看、資料正確或網格檢查通過，都不能代替最終星點外觀驗收。
- 技術檢查用來保護成果，不能把「沒有新增折角」「星點落在三角形上」當成已符合原圖。
- 兩張子票可平行，各自隔離修改；頭頸／衣領、手腕／袖口的交界須明列並在整合時檢查。未驗證的候選不得悄悄替換使用者正在看的版本。
