# 02 — 可重播與逐格檢查的鏡頭／文字流程

- Spec：`../spec.md`
- Blocked by：無

## 交付成果

在隔離驗證頁提供可操作、可重播的兩段同方向外擴鏡頭與開場文字流程，並能按時間檢查中間畫格。第一段 0.9 秒，文字完成後可點擊／鍵盤繼續或等待 3 秒自動繼續。

本票可使用現有固定點雲驗證控制流程，不等待 01 的形體修正結果。負責 R01、R04 的控制行為，以及 A04、A05、A07 中不依賴最終人物造型的部分；全程遵守 R06、A11、A12。最終人物構圖、火種入鏡、途中換章節及網站銜接仍需 03 實際接合後複驗，本票完成不代表 A04、A05、A07 已在最終畫面全部通過。

## 驗收條件

- 開工先讀 `../agent-brief.md`、Spec 最新核准要求與 U01–U08。相機／測試通過不得宣稱人物外觀通過；最終首尾鏡頭配合 A13 的原版近景與全景，背面須是真正微仰視並符合參考透視。
- 最新模型的同鏡頭素模／材質／均勻點／最終點比較、八方位、雙手近照與逐時間檢查可操作；來源與版本清楚標示，不讓舊 refine 模型或僅網址版本號充當新模型證據。
- 完整播放證據必須確認每個受驗畫格已實際渲染人物；若畫格空白，先區分產品缺陷與擷取失敗，查明後重驗，不以相機狀態數值宣稱人物持續可見。

- 隔離頁能完整播放正面停留、第一段轉動、背面停留及後段拉遠流程，也能重播及檢查指定時間的中間畫格；保留原有角度／形狀檢查能力。
- 第一段轉動 0.9 秒；兩段相機旋轉方向一致，移動段向外、文字停留段構圖穩定。後段沒有倒轉或先回舊近景再拉遠的控制行為。
- 在實際播放及時間檢查中，鏡頭使用同一基礎人物與星空，不以人物前後樣本插值或視角換圖實現運動；保留正常微浮動與光照變化的語意。
- 正面及背面文字完成後，點擊或原有鍵盤操作可繼續；未操作時從文字完成起等待 3 秒自動繼續。文字未完成時的操作、快速重複點擊與重播不跳亂流程或卡住。
- 提供實際控制流程的完整播放、時間／角度畫格及相應狀態機檢查，分清相機／互動證據與尚待 01、03 驗證的人物品質、最終構圖及整合結果。
- 已發現的控制或播放缺陷修正後，複驗原時間位置及受影響流程；保留未提交工作及舊實驗，維持隔離狀態，不把現有形體限制隱藏成視覺通過。
