# 01 — 可從各方向檢查的固定人物

- Spec：`../spec.md`
- Blocked by：無

## 交付成果

在現有隔離驗證頁展示同一份完整伸手人物的固定立體星點，可停在正面、左右側、背面及過渡角度檢查。必要時使用通過人物與姿態一致性檢查的少量側面補圖，保留原畫美感並修正髮束、肩頸、衣領、色彩與接合。

本票負責 R02、R03 的人物形體部分與 A01、A02、A03；全程遵守 R06、A11、A12。後段鏡頭與第一章銜接由 03 負責，不以形體通過宣稱完整開場已完成。

## 驗收條件

- 開工先讀 `../agent-brief.md`、Spec 最新核准要求與 U01–U08。交付同時覆蓋 A13：首張近景與末張全景必須和原版一模一樣或幾乎一樣；可見的頭部傾角、肩線、衣帶與手部差異不能只列為來源限制後通過。
- 真實模型先修正到配合原畫的姿勢、比例、輪廓；左右手需自然，尤其修正使用者否決的右手指形／姿態。點落在真實三角形與五指數量正確，都不能替代形狀驗收。
- 最新模型須可實際自由旋轉；同鏡頭對照素模、材質模型、均勻點與最終星點。至少八方位及連續 360 度，雙手有足以辨認指節的近照，星火全顯示時驗證所有主要角度及完整自轉。
- 提供首尾原版／候選並排與疊圖，以及背面參考對照。完整表面、密度、語意部位、姿態與原圖相似度分別判斷；任何一項失敗即繼續修正。不得用裁掉真實表面、浮動描邊或換圖取得首尾假吻合。

- 正面、左右側、背面及過渡角度皆可實際操作檢查，保持同一個第一姿態人物；髮型、衣服、伸手方向及角色一致。若使用側面補圖，附與原素材的一致性檢查證據。
- 單色形狀與原圖色彩可分開檢查；髮束、臉、頸、衣領、肩與接合符合 A02，沒有仍明顯可見的圓殼、直筒、扁薄、缺口、黑洞、色彩拉伸或亮度斷層。
- 從第一輪候選即能檢查完整伸手姿態的基本形體；交付時全貌的輪廓、手指、物件及手掌位置關係符合 A03，不只交付頭肩截段。
- 改變觀察角度時仍使用同一份基礎人物形體與表面色彩；法線與修正後表面相符，粒子材質持續成立。有限座標等程式檢查只能補充，不能替代上述視覺證據。
- 提供當前候選的角度及單色／彩色畫格；每個已處理缺陷均能對照修正前後結果並複驗。明顯缺陷尚存時繼續修正；需擴大範圍的取捨依 Spec 帶證據討論。
- 檢查結果仍留在隔離實驗；保留原主頁、未提交檔案及歷史實驗，不把本票產物直接覆蓋主站。
