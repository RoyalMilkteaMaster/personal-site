# 03 — 完整繞拍整合主頁並完成驗收

- Spec：`../spec.md`
- Blocked by：01 — 可從各方向檢查的固定人物；02 — 可重播與逐格檢查的鏡頭／文字流程

## 交付成果

將 01 的人物與 02 的鏡頭／文字流程接合，先在隔離頁完成形體及動畫視覺驗收，再讓主頁呈現同一人物、同一星空的完整開場，直接銜接第一章全貌。原有章節、手持物、微浮動、星光、版面適應及失敗降級持續可用。

本票完成 R01、R02、R03、R04、R05、R06 的整體需求與 A01、A02、A03、A04、A05、A06、A07、A08、A09、A10、A11、A12 的最終複驗，尤其承接 02 尚未能獨立驗證的最終構圖及網站互動。

## 驗收條件

- 開工先讀 `../agent-brief.md`。除 A01–A12 外，必須通過 A13 與 U01–U08：首尾和原版幾乎一致、完整 3D 旋轉、自然雙手與掌心星火、背面微仰視均成立。v9 已被使用者否決，不能作為視覺關通過依據。

- 使用 01 的實際人物與 02 的實際流程，在隔離頁重看單色／彩色關鍵角度、完整播放及兩段中間畫格；符合 A01–A05 後才整合主站。若接合暴露造型、遮擋或鏡頭缺陷，先在隔離候選修正並複驗，不能沿用前票的局部通過取代整體品質。
- 主頁順序為正面頭部近景、同姿勢背面頭肩、原本完整人物；第一段 0.9 秒，背面略由下往上且不拍到腰。兩段同方向向外、人物持續可見，不倒轉、不回舊近景再拉遠、不換圖或重排人物冒充繞拍。
- 火種前兩鏡不可見、最後全貌才出現；其位置與手掌相連。開場最後與第一章初始畫面連續，沒有切回另一份正面人物；全貌及手指仍維持原畫品質。
- 正面及背面文字完成後的點擊、鍵盤繼續、3 秒自動繼續、文字未完成操作、快速點擊、品牌重播及開場途中切章節，實際操作均無狀態錯亂、人物消失或內容卡住。
- 三章節內容配置、姿態及可擴充作品資料保持；共用粒子池、背景參與重構、文字同步、手持物旋轉、微浮動與少量不同步星光符合 A08。
- 在主頁實際檢查縮放與既有版面適應、減少動態偏好、素材失敗及 WebGL 不可用情境，個人內容仍可閱讀及操作，符合 A09。
- 在相同瀏覽器與視窗等條件下比較修改前後載入與播放效能，記錄環境、結果、可見卡頓與未檢查限制，符合 A10；型別、建置與必要回歸檢查另列證據，不代替視覺驗收。
- 每個已處理缺陷有角度／時間與修正前後畫格，複驗同一位置及受影響的完整播放、整合行為；交付前自行完成當前版本的完整播放與中間畫格檢查，符合 A11。
- 正式頁面能使用正式程式／素材運作，不依賴隔離服務或被忽略的實驗路徑；保留既有未提交檔案與歷史實驗，沒有未授權重置、清理、發布或改走否決路線，符合 A12。
- 若仍有明顯視覺缺陷，持續修正與複驗；若需改動原畫、增加範圍外素材或更換方案，依 Spec 提供具體證據討論，不能降低標準後宣稱已完成。
