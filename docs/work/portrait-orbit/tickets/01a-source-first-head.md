以使用者滿意的原始星點圖決定整體姿態、比例、髮臉輪廓、下巴、頸部粗度與長短、肩領關係。現有GLB只是輔助，原本歪頸、凹臉或側面失真不構成保護條件。優先重用可用成果，必要時局部重塑，不回到被否決素模無依據重建。

先建立整頭相對身體向後的合理姿態，髮、臉、耳側、下巴一起考慮，頸根自然連接。不得用只壓臉、局部亮線或領口修復代替整體頭部修正。先大形後细修；位移量以原圖和全方向自然度決定，沒有硬性小角度或全頭不動限制。

首輪即提交原圖／保留版／候選的近景、全景及0/45/90/135/180/225/270/315同鏡頭對照；明列整頭姿態、髮臉層次、下巴輪廓與頸肩關係的改變。側面沒有原圖真值時只主張合理延伸，不虛構來源。外觀改善後才進一步細修星點、異常光線與資料。單色/材質/均勻點/最終星點均可檢查，最終星點才是外觀驗收。

寫入獨立 work/model-trial/source-first-head-a1；不得覆寫任何凍結輸入、主站或使用者正在看的預覽。起點可選已保留完整版本，說明理由與精確hash；保護非任務部位的已有成果，不能把現有不自然的頭頸當成不可修改。列明衣領/肩部交界實際幾何及資料改動，供01B及整合檢查。

可採用成果需有真實表面/法線/星點身分與遮擋一致性、局部形體健康、雙端原圖對照、全方向及完整播放、可回復且拒絕重複套用的變更包。先做與修正相關的驗證，避免在外觀未改善時反覆包裝全量證據。Ready for Review後凍結，不自我核准、派Reviewer或修改主線。一次失败要說明方法原因，不能以數值變好掩蓋視覺失敗。
