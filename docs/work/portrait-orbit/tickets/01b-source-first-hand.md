原圖手势、掌向、指形、前後層次、腕部與袖口關係是目標。原GLB手勢本來不自然，不能當成答案。可重用可辨識指體，但原有長度、彎曲與姿態不是絕對限制；小幅整根微調是優先方法，不是禁止必要局部重塑的驗收條款。

先確認掌心/手腕大形與五指語意對應，再調整各指根、彎曲及掌部連接。禁止僅將正面指尖投影擬合當成成功；變形範圍需依真正部位連接，避免跨指牽連、扭折、拉薄、拉長、寬橢圓或手疊手。若需要大幅位移，先驗證掌向、對應點及變形方式，不沿錯誤方向持續掃參數，也不因角度較大就一律否決合理修形。

首輪提供原圖／保留版／候選全景、正面與左右側及斜側手部近照，說明掌/指/腕改善。逐角度看自然度，再做完整星點與星火驗證。不能把五指存在、射線窗口數量或零新增折角代替形狀驗收。

寫入獨立 work/model-trial/source-first-hand-b1；不得覆寫凍結輸入、頭部工作、主站、使用者預覽。選擇保留版本作起點並記錄hash與理由；失敗試作僅作反證，不以最新版本號推定較好。腕/袖口接合可在必要範圍修正，明列實際交界改動；頭頸及其他已可用區域保持不變。

有可採用形體後再做最終星點傳遞與原圖線條比較，保留既有退役舊手輪廓的語意，避免新舊輪廓重疊。真實掌心錨點與星火尺度、旋轉、間距須重新驗證。最終同一模型雙端及八角度/連續360都成立，資料/法線/部位身分一致；交付可重現、可回復、拒絕重複套用的變更包。Ready for Review後凍結，不自我核准/派Reviewer/改主線。
