# 每位 Agent 開工必讀：人物星點修正

## 要達成什麼

首張臉部近景與末張正面全景，必須和原版一模一樣或幾乎一模一樣；中間是同一個形狀正確、表面完整的 3D 人物，以相同方向從臉轉到微仰視背面，再到正面全景。這兩項必須同時成立。

使用者提供的 Tripo 模型是空間支架。要改模型來配合原畫，不是把原畫改成模型現有的樣子。來源圖檔保留只是保護資料，不能當成畫面保留的驗收。

## 修改前必須回報給 Coordinator

- 用自己的話說明首尾與 3D 兩項硬目標。
- 指出本次責任部位、已觀察到的具體錯誤、對應 U 編號與畫面。
- 說明要改哪些真實形狀／姿勢，以及如何避免影響其他部位。
- 列出預計修改的模組／資料、共同檔案整合者及實際驗證方式。不能只回答「已讀」。

這是派工理解檢查，不要求使用者再次核准已說明的需求。Coordinator 發現誤解必須糾正後才讓該 Agent 修改。

## 分工與防止衝突

- 手部：左右手腕掌指形與姿態、掌心星火。臉髮：頭頸姿勢、輪廓與全頭密度。衣服：領肩袖衣帶、厚度與完整性。每位負責自己部位的整圈檢查。
- 共用模型與生成流程只有一位整合者寫入。部位修正分開交付；不能多人同時覆寫相同 GLB／陣列。相機／渲染也保持單一寫入者。
- 使用者指定實作 Astra／Medium；獨立檢查 Sol 5.6／High。實際配置與執行狀態記在派工紀錄，不寫成 Ticket 的產品需求。
- 不為了修正放寬首尾外觀，不裁掉應有表面，不新增貓貓星座、彗星白光、換圖或快轉。

## 怎樣才算檢查過

在**最新模型**的可旋轉頁操作整圈，並保存 0／45／90／135／180／225／270／315 度。同一相機、時間與視口下比較素模、材質模型、均勻點及最終星點；雙手另放大到能辨認指節，星火全顯示再看完整自轉。`refine.html?v=4` 證明此種旋轉檢查可操作，但裡面的舊修整模型不能冒充最新產物。

首尾各提供原版與候選的同視口並排及疊圖，逐部位核對；背面另比參考。看完整轉場，核對背面轉入／停留／轉出；若證據出現空白人物，必須查明與重驗。

每位回報 U01–U08 的通過／失敗／未檢查，附版本、角度、近照／錄影與理由；超出分工則明確交給指定同伴。整體不能有未檢查項，也不能靠三角形誤差或含大量背景的 RMSE 抵銷肉眼可見缺陷。
