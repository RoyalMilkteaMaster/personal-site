# R9 有效流程與新模型重做

來源核對：raw-integrated-r9/result.md、compose.py、prepare.py。
R9 本身 byte-identical r8 mesh，不新增幾何delta；沿用600000表面點，合入頭部3521原圖參考點及939面積補點，4216底層點調整靜態support。原圖参考RGB與點徑分支避免重複打光；完整表面負責遮擋；固定相機繞行、背景星空與掌心星火。r9藝術外觀是使用者現在認可的比較版本，但舊結果報告並未宣稱原圖完全一致。

新流程依使用者最新要求：
1. 新fantasy GLB完整形體固定，不套舊變形。
2. 依新三角面生成固定表面星點，使用新UV材質建立直接預覽。
3. 原圖明暗、色彩、重要線條在新表面重新建立對應；新點不可假稱原始canonical IDs。先修呈現，再依必要證據處理形體差異。
4. 星空、掌心星火與繞拍，驗证所有方向及雙端原圖比較。
5. ONE Opus5 MEDIUM reviewer及Root實際UI驗证後，才可進一步主站整合。

目前240000新表面點初版已實際載入；Root見全景偏暗、抬手90可讀但指緣弱，正在要求呈現調整。非完成或藝術核准。原圖資料與舊模型位置/索引須分清：可重用原圖美術依據，不能移植舊mesh surface binding。
