## 成果

- 原本第一姿態、臉、全景構圖、伸手星火與原畫星點質感保持為視覺標準。
- Tripo 模型僅提供空間支架，須調整到配合原圖的姿勢、比例、輪廓，再用模型估算取樣點沿觀看射線的深度。
- 先用線框檢查頭、肩、手肘、手掌、衣服的空間結構，之後使用同一份固定 XYZ 與固定色彩星點。背面與側面可補原圖遮擋區域的點，但從建構時就存在，不隨角度更換、插值或交替淡入淡出。
- 鏡頭順序：臉部近景 → 背面頭肩 → 原本正面全景；全程同方向旋轉，結尾同一個場景，不另換正面 renderer 或點雲。
- 取消貓貓星座與彗星白光替換回程。不得用遮蓋或突然加速掩蓋形體問題。
- 背面參考仍是使用者所附 rear-reference.png；紫色髮絲、衣料、金色裝飾皆以星點呈現。
- 保留原下載模型與原圖，不覆蓋或改造來源。沿用已安裝本地工具，不提交外部生成或發布。

### 驗收

1. 模型對齊有可看的線框正面與中間角度，能看出姿勢與輪廓確實比原始 Tripo 更接近原圖；不可只有放大頭部或端點投影公式。
2. 整段只有一組持久人物座標/色彩與一個一致投影流程；每個 ID 的位置與基礎顏色不因相機角度改變。
3. 正面圖像位置維持原取樣投影；近景與全景需實際比對。視角依賴光照/遮擋可以改變，不可用角色替換補足。
4. 側面、背面、過渡角度具有合理厚度、手臂關係、髮型、衣領與遮擋，沒有雙層人物、尖刺或薄紙片；逐角度截圖與完整播放另行審查。
5. 鏡頭角度單調、不跳躍，臉→背→全景順序正確。縮放、暫停、重播、手機版與錯誤訊息可操作。
6. 數學測試只證明對應數學條件，不能替代視覺驗收。尚有明顯缺陷需如實列出，不以測試通過宣稱完成。
