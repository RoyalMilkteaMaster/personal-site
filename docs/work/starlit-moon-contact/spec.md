# 滿月合照、品牌文案與聯絡奶茶

## 問題
現有個人照片未融入星空主題，作品及聯絡文案尚未呈現使用者希望的活潑口吻；聯絡區右側留白缺少品牌物件，近況仍是暫用內容。

## 目標
在既有星空主預覽內完成滿月合照、五件程式作品文案、雙語聯絡內容與獨立 3D 貓貓奶茶，以及四項近況。沿用既有架構，精簡開發；保留已滿意的背景、人物與卡片互動。

## User Stories
1. 身為訪客，我希望在關於我看見融入月面的本人與貓，認識作者並感受到一致的星空風格。
2. 身為訪客，我希望透過活潑的作品介紹與最新近況，了解作者正在做什麼。
3. 身為可能合作的人，我希望聯絡區清楚表達可聯絡的主題，並保留可用的聯絡入口。
4. 身為英文訪客，我希望切換語言後得到等義、同樣親切的新內容。

## 需求與行為

### R1 滿月合照
- 在「關於我」目前右側合照的位置，改為符合既有深色星空風格的滿月。
- 使用原本本人與黑白貓的合照；人與貓淡淡融入月球紋理，仍可辨識，不能變成與本人無關的新面孔或新貓。
- 銀白、淡奶茶金的月光與柔和光暈，呈現圓滿月面及紋理；不是把原矩形照片單純加上圓框。
- 保留左側既有人物星空場景；本次不是替換或重做該人物。
- 桌面及手機保持月面與合照主體可辨，不壓住自我介紹。

### R3 聯絡區與 3D 貓貓奶茶
標題：
> 想約出來，一起喝杯奶茶嗎？

定稿內文（保留顏文字）：
> 無論是聊聊 AI 應用、想交流一個有趣的點子、又或是討論專案合作、揪團參賽，還是委託開發、職缺邀約，都歡迎聯絡我！(´▽｀)

- 在聯絡區標題／介紹右側原有空缺放現有 3D 貓貓奶茶；是既有奶茶模型，不是新設計的杯子、作品奶茶圖標或貓娘桌寵。
- 奶茶直接出現在目前內容背景，沒有自己的星空、矩形底板或第二個人物場景。它在視覺上與左側人物分屬不同空間，不跟著人物相機移動。
- 臉的那面大致朝向讀者，緩慢向左、向右來回轉動；不做 360 度自轉，也不能轉到完全背面。具體尺寸與擺角依這個可觀察條件調整，不預設未核准數值。
- 保留現有 GitHub、Instagram、Email 入口與目的地；不恢復 LinkedIn、不新增表單。
- 窄螢幕依既有響應式排版容納物件，文案與聯絡入口不被遮擋，奶茶不攔截連結或捲動。

### R4 近況與目標
以四項呈現：
- SEO & AEO｜認真研究中
- 《星結奇緣》｜遊戲開發中
- 《偽典》｜小說撰寫中
- 隨緣接案中

不自行新增目標、期限或承諾。不把 SEO/AEO 研究近況擴大為這次要實作搜尋優化。

### R5 中英文同步與既有行為
- 新增及替換文案均同步英文，保留原意、活潑親切的口吻與對應作品；中文以以上定稿為準。
- 英文翻譯屬本次交付，不新增成效保證或不存在的產品能力。沒有核准的官方英文書名／遊戲名時，保留中文專名並翻譯狀態，不自行命名。
- 切語言保持目前章節及原有狀態行為；兩語都須實際檢查長文排版。
- 每次离開再進作品先顯示五個 icon，點選後才播放既有火焰並展開；同章多卡與語言切換的既有行為維持。
- 已核准的接觸驅動 0.5→3.5px 外框、明暗流動、無外火舌、背景星色金50%／藍25%／紫25%、雲星共同1.5秒淡出、漂移與接縫遮罩皆維持。

## 實作決策
沿用 docs/planning/architecture.md 的現有前端、素材、章節及生命週期責任，本輪不重設架構。

- 資料與所有權：projects 保持唯一作品來源；site-copy 管理雙語頁面文案；照片與奶茶沿用既有本機資產，必要正式衍生資產隨網站供應，保留原檔。
- 模組責任與公開介面：StarlitShell 保持版面、章節與卡片狀態；既有奶茶模型／渲染接縫承接物件。聯絡裝飾的顯示不得改變左側人物、開場相機或導覽狀態。內部組織與表現手法由實作選擇，不在此新增引擎或鎖定 shader 技巧。
- Schema、API contract 與系統互動：沿用現有雙語作品及頁面資料，不新增後端、資料庫、外部 API、登入或服務。
- 相容、遷移與技術限制：保留未提交變更及舊素材；不部署、不替換正式首頁入口。沿用章節離開／卸載資源清理、隱藏暫停、減少動態偏好，以及素材或 WebGL 失敗不妨礙文字與連結的原有要求。

## 驗收條件
- AC1：在關於我原照片位置看見滿月及融入月紋的人與貓；兩者仍可辨、色調與背景相容，桌面手機均無遮字。視覺需實際畫面確認。
- AC2：五卡中文介紹與指定內容一致，奶茶流名稱與程式作品集標題更新；英文有等義對應。完整文案可讀，既有圖標／配色／連結保留。
- AC3：聯絡標題與中文定稿一致，英文同步；所有現有聯絡入口可正常操作。
- AC4：聯絡區可見既有立體貓貓奶茶，直接融入現有背景，無附帶星空；完整左右擺轉循環均以臉朝前、不露完全背面，不隨人物鏡頭走。
- AC5：兩語近況都有四項對應內容，沒有新增小說閱讀入口或未核准目標。
- AC6：桌面與手機兩語均無文字裁切、重疊或新增橫向溢出；離開章節、回訪、切語言及重播正常，裝飾不攔截互動。
- AC7：現有火焰、外框、作品先 icon、背景照明與淡出無回歸；新增裝飾遵循既有暫停／清理及失敗可閱讀要求。

## 測試決策
- 公開行為：檢查實際中英文文案、五卡開合與切章返回、有效連結、奶茶完整左右擺轉、手機閱讀及既有裝飾生命週期。
- 測試接縫：沿用資料／純行為測試與現有正常主預覽瀏覽器驗證；型別及建置依專案既有方式。只增加與本次風險相稱的回歸檢查。
- 不耦合實作細節：不以固定 DOM 層數、shader 字串、點數或靜態圖代替動畫與美感驗收；不為可逆文案變更建立逐字鏡像測試。
- 以正常主預覽的桌面／手機、中文／英文畫面呈現結果；說明實測環境，不把 headless 證據宣稱為真機效能。

## 不在範圍內
