# 03 — 聯絡區 3D 貓貓奶茶

- Spec：`../spec.md`
- Blocked by：無

## 交付成果
依 R3 在聯絡區右側空缺呈現既有 3D 貓貓奶茶，直接融入內容背景、正面大致朝向讀者，緩慢左右擺轉；與左側人物視覺空間及相機分離。

## 驗收條件
- 覆蓋 AC4，以及裝飾相關 AC6、AC7。
- 使用現有奶茶模型；不是另造杯子、作品圖標或雪絨桌寵。無附帶星空、矩形底板或第二個人物場景。
- 實際觀察完整擺轉循環：臉大致朝前，不轉到完全背面、不做 360 度自轉；不可只以静態截圖判定。
- 切章與人物相機動作不會把聯絡奶茶帶入人物場景；保留既有開場及人物呈現。
- 桌面右側留白及手機響應式佈局不遮文字／入口，不攔截連結與捲動；定稿文案由 02 負責，完成後由 04 合併驗收。
- 切離、隱藏、卸載與減少動態遵循既有生命週期要求；素材／WebGL 失敗仍可閱讀並聯絡，不留下持續工作的裝飾資源。

## 必要寫入範圍
聯絡區裝飾、其局部樣式、既有奶茶模型／渲染接縫的必要接入。與 01／02 共用 Shell 或樣式時按區塊整合，不覆蓋照片或文案修改；共享模型若需調整，必須確認既有使用處不回歸。
